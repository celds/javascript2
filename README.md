#Social media application

##Description
This project is a social media application where you can register/login, see your own posts
plus other people's posts, you can also create posts and check individual posts. You can also
view other people's comments and reactions under a post when you click on the post. 

##Technologies
-HTML
-CSS
-Javascript



##How to run
1. Clone repository
2. Open the project in your code editor
3. use live server extension to view it live locally
4. register an account or login if you already have one, the login | Register is in the header, use a valid noroff email address for register/login
5. now you can look at your profile and your feed and make posts.
